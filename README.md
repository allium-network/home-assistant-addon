# Allium Mesh: Home Assistant Add-on Repository (retired)

**Allium Mesh is retired and switched off.** Its final release (0.3.3) runs
nothing: no Snowflake proxy, no Tor hidden service, no panel. If you have it
installed, update to 0.3.3 and then uninstall it.

For remote access to Home Assistant, use
**[Allium Connect (Home Node)](https://github.com/allium-network/home-assistant-addon-connect)**:
native apps, no open port, and an optional Snowflake proxy with a monthly data cap.

Details: [allium-mesh/DOCS.md](allium-mesh/DOCS.md).
