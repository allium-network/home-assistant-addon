# Allium Mesh: Home Assistant Add-on (retired)

**Allium Mesh is retired and switched off.** Since version 0.3.3 the add-on runs
nothing: no Snowflake proxy, no Tor hidden service, no sidebar panel. It prints a
short notice and exits.

## What to do

1. For remote access to Home Assistant, install
   **[Allium Connect (Home Node)](https://github.com/allium-network/home-assistant-addon-connect)**.
   It has native apps and needs no open port. It can also run a Snowflake proxy for
   censored users, with a monthly data cap you set in your dashboard.
2. Uninstall this add-on: **Settings > Add-ons > Allium Mesh (retired) > Uninstall**.

The old `.onion` address for Home Assistant stops working with this release.
